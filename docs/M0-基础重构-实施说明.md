# M0 基础重构 · 实施说明

依据 `docs/产品与技术设计方案.md`（§4 领域模型、§5 客户端架构、§11 M0 交付项）执行。
本文件是 M0 的实现契约：**范围、目录结构、接口与实体的精确规格、测试要求、验收清单**。

## 1. M0 目标与验收

- 目录重组为 `lib/core | lib/domain | lib/data | lib/features`，删除遗留死代码。
- 移除页面内业务状态：聊天列表/消息不再存放在 widget `State` 或 `AIService` 内存单例中；
  改为 `ConversationRepository`（本地持久化）驱动的响应式数据流。
- 建立领域模型（实体 + 值对象 + 枚举）、错误模型、少量而深的仓储/服务接口、依赖注入。
- 本地数据库（Drift）接入：`conversations`、`messages` 两表 + 迁移框架（schemaVersion=1）。
- 保留现有界面的视觉结构与交互（M0 是重构不是重设计）；UI 文案保持中文。
- 补齐单元测试（领域层）+ 仓储测试（Drift 内存库）+ widget 冒烟测试（内存适配器，不触网）。
- 验收命令：`flutter pub get` → `dart run build_runner build` → `flutter analyze` 0 issues → `flutter test` 全绿。

## 2. 明确不做（防止蔓延）

- 不做任务/日历/AI 计划的 UI（M1）；`Task`/`Project`/`CalendarEntry`/`AIPlan`/`HealthRecord`/`Achievement`/
  `SyncOperation` 仅建立领域模型与接口，不建表、不做实现、不接 UI。
- 不做同步引擎实现（M2）：`SyncEngine` 只声明接口。
- 不做设置持久化（M1）：`AIProviderProfile` 保存在内存 `SettingsStore`；API Key 不进数据库。
- 不改视觉设计；不加新页面；不动 `pubspec.yaml` 与 `analysis_options.yaml`（由协调者统一处理）。
- 不实现语音/图片/健康功能（M3/M4）。

## 4. 领域规格

### 4.1 SyncableEntity（基类）

所有可同步实体继承它（§4.2 状态约束）：

```dart
abstract class SyncableEntity {
  final String id;
  final String userId;
  final DateTime createdAt;
  final DateTime updatedAt;
  final DateTime? deletedAt;   // 墓碑，软删除
  final int version;
  final String deviceId;
}
```

不可变模型：`final` 字段 + `copyWith`。所有实体类注释用中文。

### 4.2 实体清单（字段规格）

- **User**（SyncableEntity，userId==id）：`name?`
- **Workspace**（SyncableEntity）：`name`
- **Conversation**（SyncableEntity）：`title`, `isArchived`(bool, default false),
  `lastMessagePreview?`, `lastMessageAt?`
- **Message**（SyncableEntity，id 为消息 id，无 conversationId 归属之外再冗余 userId）：
  `conversationId`, `role`(MessageRole: user/assistant/system), `type`(MessageType:
  text/voiceTranscription/imageReference/systemEvent), `content`, `status`(MessageStatus:
  sending/sent/failed), `aiModel?`, `metadata`(Map<String,Object?>, M0 恒空)
- **AIProviderProfile**（普通值对象，**不继承 SyncableEntity**，设备本地配置）：
  `name`, `baseUrl`, `model`, `temperature`(double), `maxTokens`(int),
  `streamEnabled`(bool, default false), `capabilities`(Set<AICapability>: text/vision/tools),
  `apiKeyRef?`(安全存储引用；运行时明文 key 只在内存 SettingsStore 持有，不落库)
- **Task**（SyncableEntity）：`projectId?`, `title`, `description?`, `status`(TaskStatus:
  inbox/planned/doing/done/cancelled), `priority`(TaskPriority: low/medium/high/urgent),
  `dueAt?`, `parentTaskId?`, `repeatRule?`, `sourceMessageId?`, `sortOrder`(int, default 0)
- **Project**（SyncableEntity）：`name`, `goal?`, `isArchived`
- **CalendarEntry**（SyncableEntity）：`title`, `startAt`, `endAt`, `allDay`(bool),
  `taskIds`(List<String>), `note?`
- **AIPlan**（SyncableEntity）：`conversationId`, `sourceMessageId`, `status`(AIPlanStatus:
  draft/awaitingConfirmation/applied/rejected/expired), `aiModel`, `aiModelVersion?`,
  `promptVersion`, `changes`(List<AIPlanChange>), `confirmedAt?`, `appliedAt?`, `rejectedAt?`
- **AIPlanChange**（值对象）：`type`(AIPlanChangeType: createTask/updateTask/scheduleTask/deleteTask),
  `taskId?`, `calendarEntryId?`, `payload`(Map<String,Object?>)
- **HealthRecord**（SyncableEntity）：`type`(HealthRecordType: meal/calorie/exercise/weight/other),
  `title`, `value`(Map<String,Object?>), `occurredAt`, `source`(String: manual/ai/vision),
  `confidence?`(double), `note?`
- **Achievement**（值对象，非同步）：`code`, `title`, `description`, `ruleVersion`
- **UserAchievement**（SyncableEntity）：`achievementId`, `eventKey`, `unlockedAt`
- **SyncOperation**（SyncableEntity，本地同步队列）：`entityType`, `entityId`,
  `kind`(SyncOperationKind: create/update/delete), `payload`(Map<String,Object?>),
  `status`(SyncOperationStatus: pending/syncing/synced/failed/conflicted),
  `retryCount`(int), `lastError?`, `syncedAt?`
- **SyncState**（枚举）：idle/syncing/offline/failed
- **SyncReport**（值对象）：`pushed`(int), `pulled`(int), `failed`(int), `cursor?`(String), `at`(DateTime)
- **TaskQuery**（值对象）：`status?`, `projectId?`, `dueFrom?`, `dueTo?`, `text?`
- **TaskChange**（sealed）：`TaskInserted(task)` / `TaskUpdated(task)` / `TaskDeleted(id)`

### 4.3 接口规格（少而深）

```dart
abstract interface class ConversationRepository {
  Stream<List<Conversation>> watchConversations();            // 按 lastMessageAt 倒序，不含已删除
  Future<List<Conversation>> getConversations();
  Stream<List<Message>> watchMessages(String conversationId); // 按 createdAt 正序
  Future<List<Message>> getMessages(String conversationId);
  Future<Conversation?> getConversation(String conversationId);
  Future<Conversation> createConversation({required String title});
  Future<Conversation> updateConversation(Conversation conversation);
  Future<Message> addMessage(Message message);                // 自动维护 version+updatedAt
  Future<void> clearMessages(String conversationId);          // 物理删除消息（M1 起改为墓碑）
  Future<void> deleteConversation(String conversationId);     // 软删除（墓碑）
  Future<Conversation> ensureDefaultConversation();           // 表为空时创建『AI助手』，幂等
}

abstract interface class TaskRepository {
  Stream<List<Task>> watchTasks(TaskQuery query);
  Future<List<Task>> getTasks(TaskQuery query);
  Future<Task> save(Task task);
  Future<void> applyChanges(List<TaskChange> changes);
}

abstract interface class SettingsStore {
  AIProviderProfile get currentProfile;
  Stream<AIProviderProfile> watchProfile();
  Future<void> saveProfile(AIProviderProfile profile);
}

abstract interface class AIClient {
  Future<AIResult> complete(AIRequest request);
  Future<AIResult> testConnection(AIProviderProfile profile);  // 供设置页『测试连接』
  Future<AIPlan> proposePlan(PlanRequest request);             // M1 实现；M0 抛 AppException（暂未支持）
}

abstract interface class SyncEngine {
  Future<SyncReport> sync({bool manual = false});
  Stream<SyncState> watchState();
}
```

- `AIRequest`：`messages`(List<AIChatMessage>), `profile`(AIProviderProfile)
- `AIChatMessage`：`role`(AIChatRole: system/user/assistant), `content`
- `AIResult`：`content`, `model`, `finishReason?`
- `PlanRequest`（M1）：`conversationId`, `sourceMessageId`, `request`(String)

### 4.4 错误模型（lib/core/errors/app_exception.dart）

```dart
sealed class AppException implements Exception {
  final String message;      // 中文，可直接展示给用户
  final String code;         // 机器可读：validation/network/ai_provider/storage/not_found/unsupported
  final Object? cause;
  String toString()          // 输出 code + message + cause，绝不打印 key/完整响应体
}
class ValidationException extends AppException {}
class NetworkException extends AppException {}
class AIProviderException extends AppException { final int? statusCode; final String? body; }
class StorageException extends AppException {}
class NotFoundException extends AppException {}
```

`AIService.sendMessage` 原有的“返回错误字符串”模式废弃：一律抛 `AppException`，由 UI 层捕获并以 SnackBar/气泡提示 `message`（不泄露密钥与响应细节）。

### 4.5 core 工具

- `ids.dart`：`generateId()` → `Uuid().v4()`；`newUserId()` / `newDeviceId()` 同源。
- `clock.dart`：`abstract class Clock { DateTime now(); }` + `class SystemClock implements Clock`。
  仓储实现注入 Clock，保证测试可控。
- `app_config.dart`：默认 `https://api.chatanywhere.tech/v1`、`gpt-3.5-turbo`、0.7、2000、'Chat with Alice'、'1.0.0'。
  静态常见模型列表 `commonModels: ['gpt-3.5-turbo','gpt-4','gpt-4o-mini','gpt-4o']`（获取列表是 M1）。

## 5. 数据层规格

### 5.1 Drift（lib/data/local/app_database.dart）

- `schemaVersion = 1`；`MigrationStrategy`：`onCreate` 建表；`beforeOpen` 开 WAL（与
  `await customStatement('PRAGMA foreign_keys = ON')` 一致风格即可）。
- 两张表：
  - `conversations`：id(TEXT PK, client 生成), userId, title, isArchived(bool, default false),
    lastMessagePreview(TEXT?), lastMessageAt(DATETIME?), createdAt, updatedAt, deletedAt(DATETIME?),
    version(int, default 1), deviceId
  - `messages`：id(TEXT PK), conversationId(TEXT, 索引), userId, role(TEXT), type(TEXT),
    content(TEXT), status(TEXT), aiModel(TEXT?), metadata(TEXT, JSON 字符串),
    createdAt, updatedAt, deletedAt(DATETIME?), version, deviceId
- `ConversationRepositoryImpl` 职责：
  - `watchConversations`：`select..where(deletedAt.isNull())..orderBy(lastMessageAt desc)` + `.watch()`
  - `watchMessages`：`deletedAt.isNull()` + `createdAt asc`
  - `addMessage`：写消息 + 更新所属会话 `lastMessagePreview/lastMessageAt/updatedAt/version+1`
  - `deleteConversation`：置 `deletedAt = now`（墓碑），消息不动
  - `ensureDefaultConversation`：`select().get().isEmpty` 时创建『AI助手』（幂等）
  - 所有实体统一：`id`/`userId`/`deviceId` 由调用方或 impl 用 `ids.dart` 生成；
    `createdAt/updatedAt/version` 写入时维护。
- 仓储构造函数注入 `AppDatabase` 与 `Clock`，不直接依赖 get_it。

### 5.2 OpenAI 客户端（lib/data/ai/openai_client.dart）

- 迁移 `AIService` 的 `/chat/completions` HTTP 逻辑到 `complete()`；请求体来自 `AIRequest/profile`。
- `testConnection()`：发一条极短消息（如「ping」），成功返回 `AIResult`，非 2xx 抛 `AIProviderException(statusCode, body)`（body 不得外泄给 UI，仅记日志摘要）。
- 内存实现（lib/data/memory/）：`MemoryConversationRepository`（List 内存态 +
  `StreamController.broadcast` 实现 watch 语义，行为与 Drift 版一致）、`MemorySettingsStore`（默认配置 + broadcast 流）。供测试与后续预览使用。

## 7. UI 迁移规格（保持现有视觉）

- **HomeScreen**（features/home/）：`watchConversations()`→StreamBuilder 列表；空态提示

  `lastMessagePreview` 单行省略、`HH:mm` 时间。去掉未读角标（M0 无推送概念）。
- **ChatScreen**（features/chat/）：参数改为 `conversation`（或 conversationId + title）；
  `watchMessages(conversationId)`→StreamBuilder 消息列表；发送→`SendMessage` 用例；
  等待时保持现有「思考中」指示；失败把 `AppException.message` 以 SnackBar 呈现（或气泡置为失败态）。
  保留「清空聊天记录」菜单（→ `clearMessages`）。
- **SendMessage 用例**（features/chat/application/send_message.dart）：
  `getMessages` 组装历史 → `repository.addMessage(用户消息)` → `aiClient.complete` →
